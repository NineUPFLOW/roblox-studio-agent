# Studio Agent — бесплатный AI-агент для Roblox Studio

**Studio Agent** — бесплатное расширение для браузера, которое превращает ChatGPT, DeepSeek, Gemini, Kimi, GLM, Qwen, Arena, Meta AI или OpenHands Canvas в AI-агента для Roblox Studio. Всё управление студией идёт прямо из обычного AI-чата: чтение и редактирование скриптов, запуск Luau, инспекция дерева игры, генерация ассетов. Без API-ключей, без терминала, без программирования.

Ничего платить не нужно: ни подписки, ни аккаунта, ни «чаевых». Проект полностью бесплатный и с открытым кодом.

## Как это работает

```
AI-чат в браузере → расширение Studio Agent → мост (ваш ПК) → Roblox Studio
```

Расширение работает внутри страницы чата: над полем ввода появляется панель Studio Agent. Когда вы описываете задачу, она превращается в команды, которые уходят на мост (`bridge.py`), а мост исполняет их в Roblox Studio через встроенный MCP-сервер.

Поддерживаются девять AI-сервисов: **DeepSeek** (chat.deepseek.com, рекомендуемый), **ChatGPT** (chatgpt.com), **Google Gemini** (gemini.google.com), **Kimi** (kimi.ai), **GLM** (chat.z.ai), **Qwen** (chat.qwen.ai), **Arena** (arena.ai), **Meta AI** (meta.ai) и **OpenHands Canvas** (app.all-hands.dev/canvas).

Особенности по провайдерам:

- **ChatGPT** — скриншоты и передача изображений намеренно выключены: бесплатный лимит файлов считается отдельно от сообщений, поэтому vision работал бы только часть дня. В длинных сессиях ChatGPT сжимает контекст, так что Studio Agent периодически повторяет свои инструкции (чип «Reminder»).
- **Gemini и Kimi** бывают нестабильны — это поведение модели, а не расширения: Gemini со временем перестаёт пользоваться инструментами Roblox, а Kimi иногда зовёт свои нативные инструменты вместо команд Studio Agent. Если AI отвечает текстом вместо действия — напомните ему про команды или начните новую сессию.
- **Arena** — только режим **Direct** (Studio Agent блокирует старт в Battle / Side-by-Side / Agent: он управляет одним ответом Direct).
- **OpenHands Canvas** — панель появляется только в чате режима **Code**: в Automate та же кнопка отправки создаёт автоматизацию, а Plan умеет лишь писать план, поэтому в обоих режимах Studio Agent отказывается стартовать. Запрос Canvas на подтверждение запуска в песочнице Studio Agent за вас не нажимает: команда, которую вы не подтвердили, так и помечается неотправленной.

## Установка

### 1. Скачайте архив и загрузите расширение

В архиве (или в репозитории) лежат и мост (`bridge.py`, `start.bat`, `MacOS_Start.command`), и папка расширения `studio-agent-extension` — ничего скачивать отдельно не нужно.

- Откройте `edge://extensions` (Edge) или `chrome://extensions` (Chrome)
- Включите **Режим разработчика** (переключатель справа сверху)
- Нажмите **Загрузить распакованное расширение**
- Выберите папку `studio-agent-extension`

### 2. Запустите Roblox Studio и включите MCP

Откройте Place, затем (только при первом запуске):

- **Assistant AI** в верхней панели
- **...** (справа сверху в панели Assistant)
- **Manage MCP Servers**
- **Enable Studio as MCP Server**

### 3. Запустите мост

- **Windows:** двойной клик по `start.bat` в распакованной папке. Python 3.9+ установится автоматически, если его нет.
- **macOS:** двойной клик по `MacOS_Start.command`. При первом запуске macOS покажет предупреждение («не удалось проверить… на вредоносное ПО») — это нормально для любого скрипта, скачанного не из App Store: нажмите «Готово», затем «Системные настройки → Конфиденциальность и безопасность», прокрутите вниз и нажмите «Все равно открыть». Один раз и готово.

Откроется небольшое окно — значит, мост работает. **Не закрывайте его**: Studio Agent работает, пока окно открыто; можно просто свернуть.

### 4. Начните сессию

Откройте https://chat.deepseek.com (рекомендуется) или chatgpt.com, gemini.google.com, www.kimi.ai, chat.z.ai, chat.qwen.ai, arena.ai, www.meta.ai, app.all-hands.dev/canvas и создайте новый чат. Над полем ввода появится панель Studio Agent. Нажмите **Start session** и опишите, что нужно построить.

> Панель работает только на этих адресах: chat.deepseek.com, chatgpt.com, gemini.google.com, kimi.ai, chat.z.ai, chat.qwen.ai, arena.ai, meta.ai и app.all-hands.dev. На других сайтах она не появится.
> OpenHands Canvas — это облачное приложение app.all-hands.dev/canvas, нужен аккаунт OpenHands. Самостоятельно размещённый инстанс тоже работает, но перед загрузкой расширения добавьте его адрес в `host_permissions` и `content_scripts` в `manifest.json`.

## Что умеет AI

- читать и редактировать скрипты;
- выполнять Luau прямо в Studio;
- осматривать дерево игры и инстансы;
- генерировать меши, материалы и модели;
- искать и вставлять модели из Creator Store;
- управлять плейтестом;
- помнить ваш проект между сессиями — постоянная память живёт внутри самого Place (`ServerStorage.StudioAgent.Memory`).

## Индикатор статуса в панели

| Цвет | Значение |
|------|----------|
| Зелёный | мост и Studio готовы (открыт Place) |
| Жёлтый | мост работает, но Studio ещё недоступна — откройте Roblox Studio, загрузите Place или включите её MCP-сервер (наведите на индикатор — будет точная причина) |
| Серый | мост выключен — запустите `start.bat` (Windows) или `MacOS_Start.command` (macOS) |

## Требования

- Windows или macOS
- Roblox Studio (поддержка MCP встроена)
- Microsoft Edge или Chrome
- Python 3.9+ (на Windows ставится автоматически)
